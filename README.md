Atomic Mass Calculator

A responsive, terminal-based Python application designed to assist STEM students and educators in calculating core atomic properties. By inputting the quantity of fundamental subatomic particles, the program dynamically identifies the corresponding element from an embedded data matrix and computes structural values.

Features
* **Subatomic Logic Calculations:** Automatically derives Atomic Number, Mass Number, and electrical Net Charge (\(p^+ - e^-\)).
* **Data-Driven Matrix Identification:** Utilizes an optimized nested dictionary loop to accurately map proton counts against historical chemical data to extract element names.
* **Defensive Input Handling:** Built using rigorous integer validation to ensure mathematical equations run without runtime exceptions.

 Built With
* **Python 3** - Structural logic, conditional statements, and dictionary maps.

What I Learned
Through this project, I strengthened my understanding of Python data types, specifically forcing input values from default strings into mathematical integers (`int`). I also gained practical experience navigating complex data structures by deploying a `for` loop to search through multidimensional key-value pairs (nested dictionaries) efficiently.
